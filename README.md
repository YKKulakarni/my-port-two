# Yalagurappa Kulkarni — React Frontend Portfolio

A modern, responsive developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and React Icons.

## Purpose
This portfolio presents Yalagurappa Kulkarni's transition from ReactJS / frontend technical training into a professional ReactJS / Frontend Developer role.

## Features
- Responsive single-page portfolio
- Sticky navigation with mobile menu
- About, Skills, Experience, Projects, Strengths, and Contact sections
- Downloadable resume
- GitHub, LinkedIn, and email links
- Framer Motion entrance animation
- Accessible controls
- Vercel-ready configuration

## Run Locally
```bash
npm install
npm run dev
```
Vite typically runs at `http://localhost:5173`.

## Production Build
```bash
npm run build
```
Output directory: `dist/`

## Updating Project Links
Project links are maintained in `src/data/portfolioData.js`. CurtainArt and Organic Basket currently include their published GitHub and Vercel URLs; update the remaining project links when they are ready.

## Resume
The resume is stored at `public/resume/Yalagurappa_K_React_Frontend_Developer_Resume.docx`.
